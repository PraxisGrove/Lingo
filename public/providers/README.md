# Provider icons

These local SVG assets identify the service chosen by the reader. The UI uses
neutral white tiles so the original logo colors and monochrome marks remain
legible in light and dark themes. Kimi's white mark retains a dark backing.
Custom endpoints use a generic connection
symbol instead of guessing a vendor from a user-supplied profile name.

Source: [Lobe Icons](https://github.com/lobehub/lobe-icons),
`@lobehub/icons-static-svg@1.95.1`.
Pinned source revision: `49a2130df7bfa5eb1b088261bff20a37e2967789`.
The full MIT copyright and license notice is included in [LICENSE.txt](./LICENSE.txt)
and distributed with the extension. Brand marks are used to identify the
configured services; their trademarks belong to their respective owners.

The selected SVG contents are unchanged; file names match Lingo's provider IDs.
No icon package or CDN request is needed at runtime.
