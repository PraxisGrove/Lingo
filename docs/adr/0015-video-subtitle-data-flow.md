# 视频字幕按读者开启发送，并只向前翻译有限时间窗

视频字幕是持续的页面内容流，默认关闭，只有读者在视频上的 Lingo 按钮或弹窗中开启后，才读取字幕文件并发送给当前翻译服务；也可以为单个网站选择总是开启。开启前不嗅探、不下载字幕文件，开启后只翻译播放位置之后约 90 秒的句子，不一次性发送整条字幕轨。跨源字幕文件由后台以不带 Cookie 的请求读取，只接受字幕格式的地址并限制大小，不作为通用代理。缓存仍按原文、语言和服务隔离，不记录视频或字幕文件地址。不在页面主环境注入脚本，也不尝试绕过视频网站对自动化或未登录访问的限制；拿不到字幕文件时，改为逐行翻译播放器已显示的字幕。
