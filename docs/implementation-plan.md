# Lingo 实施路线

实施采用可独立验收的垂直切片。每一阶段都从真实入口走到可观察结果，不先铺设无人调用的抽象层。

## 当前交付目标：可靠的浏览器翻译插件

Lingo 以网页双语阅读和日常文本翻译为当前阶段目标，独立设计产品、交互与代码。按自身支持场景和验收结果描述能力，不以与其他产品的功能条目比较作为完成标准。

截至 2026-10-20，阶段 0–7 的核心链路已实现，当前重点是新增能力收尾与阶段 8 的发布验收。版本仍为 `0.1.0` 开发版；功能实现、本地自动化通过和真实环境可用性分别记录，不用测试数量替代日常可用性结论。

| 方向 | 当前状态 | 下一步验收 |
| --- | --- | --- |
| 网页与文本翻译 | 核心链路已实现；包括自动翻译、动态内容、开放 Shadow DOM、长段落、划词、输入确认与撤销 | 至少 20 个真实站点、真实服务质量与账户限制、长页面性能 |
| 阅读与服务配置 | 原生浏览器侧栏、阅读样式、多语言、服务管理、模型发现、显式备用服务链已实现 | 首次配置、切换服务/模型、错误恢复和键盘操作的真实使用验收 |
| 浏览器端侧翻译 | Chromium Translator API 与 offscreen 桥接已实现，设置页提供语言包下载入口 | 支持的 Chromium 版本、语言组合、真实语言包下载与离线翻译 |
| 词汇学习 | 英文难词高亮、悬停释义、已知词、生词本及 Anki TSV 导出已实现 | 真实文章的分词与高亮准确性、词卡交互和导出使用 |
| 网关接入 | 自定义请求头、可选密钥、请求预算与模型协议路由已实现 | 各网关实际部署配置；模型发现与生成能力分别验证 |
| 视频字幕 | 首版链路已实现，默认关闭；字幕来源、分句、时间窗翻译、播放器叠加与设置已接入 | 真实视频网站、登录条件、拖动进度、切集/导航、停止恢复、延迟与调用成本 |
| 跨浏览器发布 | Chrome/Firefox 构建与自动化流程已建立，尚未完成发布验收 | Firefox/Edge 安装验收、性能基准、商店披露与发布清单 |
| 后续场景 | PDF、EPUB、OCR、图片/漫画、Safari、移动端、同步和可选托管服务尚未交付 | 按具体需求先确定结构、质量、成本、数据流向和独立验收标准 |

客户端功能开源；服务调用成本单独说明。浏览器端侧翻译提供无需 API Key 的本机路径，但依赖浏览器与语言包可用性。当前没有捆绑免密钥的远程翻译服务、官方社区规则地址或 Lingo 托管后端。

参考开源项目只用于研究行为与模块边界，保持独立实现。后续场景暂不阻塞插件阶段交付；已进入当前版本的新增能力须完成自身回归和隐私披露。

## 当前实现与验收范围（2026-10-20）

### 网页、文本与阅读入口

- 手动/自动翻译应用站点正文、界面与排除选择器；十类代表性布局在 Chromium/Firefox 中运行回归测试。
- 后台逐批返回结果，其他批次等待时页面即可呈现已完成译文；主控制入口使用 Chromium Side Panel / Firefox Sidebar，兼容 popup 入口仍保留。
- 阅读外观支持字体、字号、行高、间距、颜色与分隔方式，修改样式不重新请求翻译。
- 内联代码以不含代码正文的占位符参与翻译，响应标记校验后从本地恢复；代码块、隐藏内容和其他受保护区域仍排除。
- 原文更新只检查受影响区域，拒绝旧段落结果；SPA 通过浏览器导航事件按 frame 更新会话。
- 划词按钮/右键/快捷键、显式悬停段落翻译、页面侧边文本面板与独立文本翻译页已接通。
- 普通文本输入与 textarea 支持翻译预览、确认写回、撤销；等待期间的用户改动不会被覆盖。富文本编辑器和敏感字段不支持。
- 嵌套开放 Shadow DOM 支持动态根发现、宿主继承排除、根内样式与恢复；封闭根不支持。
- 超长段落按预算分段，格式标记在边界闭合与重开，完整校验后重组；重试复用成功片段。
- 单后台实例共享并发限制、请求启动间隔和等价批次的进行中请求；读者取消互相独立。超时中止网络请求，阻塞性服务错误停止后续批次。
- 可配置 HTTPS 规则订阅与可信发布者公钥；下载限时限量，签名失败保留已验证规则，关闭更新后不下载。

2026-10-09 的体验与代码复核及修复保留在 [复核记录](./experience-review.md)，其中测试数量是当时的历史记录。

### 服务接入与新增阅读能力

- 已有 OpenAI Chat Completions / Responses、Anthropic Messages、Gemini generateContent、DeepL、Google Cloud Translation 与 Azure Translator 适配及配置入口。
- 服务支持目录导入、推荐/手动选模、独立连接测试及显式备用链；刷新目录不覆盖手动选择，服务配置变化使缓存身份失效。
- 本地网关支持可选密钥、自定义请求头、带非敏感查询参数的地址和单服务请求预算。秘密请求头值保存在本地凭据区，不进入普通设置和诊断。
- 网关返回模型原生协议时，选模可切换到相应协议；目录发现成功不代表该模型已通过生成测试。
- Chromium 端侧翻译复用翻译编排入口；网页文本在设备内处理，语言包由用户在设置页下载。其他浏览器不承诺该能力可用。
- 词汇学习默认关闭，使用随包词频表在本机识别英文难词；悬停时通过当前服务释义，支持标记已知、保存生词和导出。

### 视频字幕首版

- 从视频按钮或当前页控制面板显式开启，也可为单个站点设置自动开启；未开启时不读取或下载字幕文件。
- 已接入 YouTube 字幕请求、Bilibili 字幕文件、页面加载的 WebVTT/SRT、HTML5 text tracks，以及部分播放器的屏幕字幕选择器。
- 文件字幕按句合并，向前翻译约 90 秒的有限窗口；拖动进度后按位置调度，已译句子可复用。没有可读字幕时显示等待状态，不提供语音识别。
- 支持双语/仅译文、字号、播放器按钮与自动开启站点管理；字幕层从普通网页翻译中排除，避免双重处理。
- 跨源字幕由后台无 Cookie 拉取，校验字幕形式的地址并设置超时和大小限制；复用当前服务与翻译缓存，不保存视频或字幕文件地址。数据流决策见 [ADR-0015](./adr/0015-video-subtitle-data-flow.md)。
- 自动化覆盖解析、分句、调度、页面叠加和本地模拟字幕源的安装后扩展流程。站点配置和模拟通过不代表对应线上播放器已经验收；登录、地区限制与播放器改版须单独记录。
- 字幕文件手动导入/导出、无字幕视频的语音识别仍为后续能力。

### 验证依据与边界

- 模型、服务契约和 UI 测试：`pnpm test`，本次路线更新时共 651 项通过。
- 页面行为：`pnpm test:browser`，在 Chromium/Firefox 中运行网页翻译、文本工具、阅读外观、词汇和字幕 fixture。
- 安装后的 Chromium 扩展：先 `pnpm build`，再 `pnpm test:extension`；覆盖真实入口、内容脚本和后台之间的消息、导航、取消、服务配置、侧栏、端侧桥接、词汇与字幕流程。
- 类型、格式与构建：`pnpm compile`、`pnpm check`、`pnpm build`、`pnpm build:firefox`。每次提交须通过完整 Lefthook 工作流。

自动化使用临时浏览器配置和本地模拟服务，不读取个人浏览器配置，也不调用付费服务。端侧桥接测试允许宿主报告不可用，不能据此认定语言包下载和本机翻译已验收。页面布局和字幕 fixture 不等同于线上站点全面支持。

README 已记录有限的真实服务检查：本地 Magpie 模型目录读取，以及 DeepSeek 目录和两个短样本的生成验证。这些结果仅证明对应配置的局部链路，不代表所有服务账户、模型、额度、计费或翻译质量已通过验收。

## 下一步执行顺序与发布清单

1. **完成新增能力回归**：字幕默认关闭、字幕源降级、进度跳转、切集/SPA、停止恢复、无字幕提示；词汇交互和端侧不可用状态；保持现有网页翻译回归通过。
2. **真实服务与语言包验收**：按协议和代表性服务记录目录、生成、认证/额度/限流、取消及备用链；端侧翻译记录浏览器版本、语言包下载、离线行为与不可用提示。
3. **真实站点验收**：至少 20 个真实站点，覆盖新闻、技术文档、社区、搜索和购物，记录代表页面地址、日期、浏览器、服务、漏译/误译范围、布局、重复请求与恢复结果。字幕另建播放器验收记录，区分文件、text track 与屏幕字幕来源。
4. **跨浏览器与性能验收**：补齐 Firefox/Edge 安装后的完整流程；对长页面、动态页面与长视频记录首屏/首句等待、CPU、内存、DOM 增长、请求次数和调用成本。
5. **发布材料与打包**：审查权限、CSP、规则更新和数据流披露；复核法律文本、词频资源归属和商店文案；核对版本/tag、Chrome/Firefox 包与安装结果。现有发布工作流生成 GitHub 草稿 Release，商店提交单独执行。

上述项目完成并保留结果前，维持开发版定位。每项验收应记录实际环境与失败项；若缩小支持范围，须同步 README、产品方案和商店说明。

## 已实现的基础阶段（0–7）

以下保留阶段拆分及验收目标，便于追溯模块边界；阶段 8 的发布标准仍待完成。

## 阶段 0：产品化基础

- 更新包名、manifest、README，完成 Dual Fold 品牌、矢量资源与浏览器图标。
- 加入标准 AGPL-3.0 文本、CLA 与贡献说明，法律文本发布前审阅。
- 建立隐私政策、权限说明和安全报告流程。
- 将现有 settings 模型升级为带 schema 版本的最小偏好模型。

验证：`pnpm compile`、`pnpm test`、`pnpm check`、Chrome/Firefox 构建均通过。

## 阶段 1：第一条端到端翻译

- 建立 Page Translation 和 Translation Orchestrator 两个 Interface。
- 内容脚本识别静态测试页的普通段落并插入译文。
- 后台通过长连接接收翻译单元，使用内存 Provider Adapter 返回结果。
- popup 支持翻译、双语对照和显示原文。

验证：一个静态文章页可以翻译并无损恢复；页面和内容脚本均无法读取测试凭据。

## 阶段 2：真实服务与首次配置

- 实现服务配置档案、凭据存储和连接测试。
- 先完成 OpenAI-compatible Adapter，再依次加入 DeepL、Google Cloud 和 Azure。
- 完成目标语言、源语言自动/手动选择与首次配置流程。
- 增加厂商契约 fixture 和错误分类。

验证：四类服务通过同一 Orchestrator Interface 工作，UI 不包含厂商分支逻辑。

## 阶段 3：可靠的页面翻译

- 实现三层内容分类和受保护内容排除。
- 保留 inline 标记、链接与强调格式。
- 支持双语对照、仅显示译文和显示原文。
- 增加 MutationObserver、IntersectionObserver 和页面 revision。
- 实现视口优先与立即翻译到底部。

验证：静态文章、无限滚动、SPA 和 iframe fixture 不重复计费，停止后无 Lingo 残留 DOM。

## 阶段 4：编排、缓存与恢复

- 实现 IndexedDB 缓存、容量管理和失效规则。
- 实现批量、并发、超时、退避、取消和局部失败。
- 完成暂停原因、失败段落重试和显式备用服务链。
- 验证后台服务工作线程重启后的重连行为。

验证：认证失败、限流、部分响应、断连和取消都有确定结果，原文始终可恢复。

## 阶段 5：自动翻译与站点规则

- 实现全局、站点和当前页面偏好解析。
- 支持站点三态策略、源语言策略和默认自动站点。
- 建立声明式规则 schema、内置规则和用户规则编辑/导入导出。
- 建立社区规则的签名、静态分发、last-known-good 和关闭更新能力。

验证：规则优先级、签名失败、离线启动和用户覆盖均有自动化测试。

## 阶段 6：AI 质量能力

- 实现有限相邻上下文和稳定段落编号协议。
- 实现术语表、翻译指令、内置模板及版本化缓存失效。
- 支持厂商原生 glossary；其他厂商通过请求约束实现，不做译后字符串替换。
- 增加结构化输出修复与逐段结果校验。

验证：混合语言、缺失段落、顺序错乱、术语冲突和长文本拆分都有固定 fixture。

## 阶段 7：完整首版交互

- 完成原生侧栏当前页控制中心和 options 管理界面，保留兼容 popup 入口。
- 加入快捷键、右键菜单和默认关闭的悬浮球。
- 展示缓存占用、权限、数据流向和脱敏诊断导出。
- 完成无服务、无权限、余额不足和不支持页面的空状态。

验证：键盘可达、屏幕阅读器标签、浅色/深色主题和窄弹窗均通过检查。

## 阶段 8：跨浏览器发布

- 在 Chrome、Edge 和 Firefox 执行统一验收套件。
- 审查 manifest 权限、远程规则、CSP、可复现构建和商店披露。
- 对长页面和动态页面做 CPU、内存、DOM 增长和请求数量基准。
- 生成商店包、隐私说明、权限说明和发布清单。

验收目标（待完成）：三个目标浏览器满足产品方案的首版成功标准，CI 产物可复现；执行项与结果边界见上方发布清单。

## 可选服务与运营路线

文档、图片、字幕导入导出与语音识别、Safari、移动端和同步按后续产品需求推进；视频字幕首版已进入当前版本，按上方清单验收。另按服务方案与验证结果评估可选的 Lingo 托管模型、官方同步实例、账户与支付、企业受管策略及运维支持。

后续能力不得改变 Community 全功能开源、BYOK 完整可用和托管服务可自建的承诺。
